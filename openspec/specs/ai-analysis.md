# AI Analysis

## Capability
MBTI职业性格测试（16种性格类型，12/24/36题三版本）。关键词提取与重要程度排序。个性化工作建议与职业发展报告。AI信息地图。每日占卜（梅花易数，纯本地计算）。项目完成分析（完成率/状态分布/优先级/趋势/逾期/团队排名/AI建议）。

## Requirements
- MBTI测试支持12/24/36题三版本选择
- MBTI本地计算类型并生成职业分析报告
- MBTI历史记录查看，支持长按删除和清空
- 关键词分析展示完整过程：预处理→候选词提取→停用词过滤→词频排序→子词合并
- AI建议包含工作建议、职业建议和发展计划
- 每日占卜基于梅花易数：年支+月+日取上卦，加时支取下卦，总和取余得动爻
- 占卜显示本卦/互卦/变卦的完整卦辞和爻辞，每日仅限一次
- 项目完成分析提供完成率、状态分布、优先级分析、7天趋势、逾期分析、团队排名和AI建议

## Scenarios

### MBTI test
GIVEN 用户进入MBTI测试
WHEN 选择题数版本并完成所有答题
THEN 系统生成对应性格类型的职业分析评测报告

### Keyword analysis
GIVEN 用户输入待分析文本
WHEN 触发关键词分析
THEN 展示提取的关键词、词频及完整分析步骤

### Daily divination
GIVEN 用户当日未进行占卜
WHEN 点击"开始占卜"
THEN 基于当前时间起卦，展示本卦/互卦/变卦的卦辞和爻辞

### Project completion analysis
GIVEN 后端有任务数据
WHEN 请求 /ai/project-analysis
THEN 返回完成率、状态分布、优先级分析、完成趋势、逾期分析、团队排名和AI建议
