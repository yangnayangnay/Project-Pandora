# UI and Theme

## Capability
月相主题自动切换（8种月相：新月/蛾眉月/上弦月/盈凸月/满月/亏凸月/下弦月/残月）。手动主题选择覆盖自动切换。底部导航栏5项。卡通快乐风格界面。专注模式（番茄钟）。生日祝福功能。

## Requirements
- 8种月相主题根据当天月相自动切换
- 切换平滑无闪烁，使用过渡动画
- 支持手动模式覆盖自动切换
- 底部导航5项：日程/视图/专注/其他/我的
- 竖屏锁定
- 描述文本通过strings.xml统一管理
- 专注模式：25分钟专注+5分钟休息循环
- 生日祝福：设置生日，显示祝福和倒计时

## Scenarios

### Auto theme switch
GIVEN 系统检测到月相变化
WHEN 应用启动或日期变更
THEN 自动应用对应月相主题，切换平滑无闪烁

### Manual theme override
GIVEN 用户在主题设置页
WHEN 选择手动模式并指定某月相主题
THEN 界面应用用户选择的主题，覆盖自动切换

### Focus mode
GIVEN 用户进入专注模式
WHEN 点击开始
THEN 启动25分钟专注计时，完成后进入5分钟休息
