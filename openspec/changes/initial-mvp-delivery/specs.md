# Spec Deltas: Initial MVP Delivery

## Added Capabilities

### task-management
任务全生命周期管理：创建、分发、接收、进度更新、确认完成、四象限、紧急程度。

### work-log-management
工作日志录入、查询、统计、十大重要工作、晨星冒烟测试。

### view-display
月/周/日视图切换、导图页四大板块。

### ai-analysis
MBTI测试、关键词分析、AI建议、每日占卜、项目完成分析。

### role-permission
5种角色权限分级、JWT认证、用户注册登录。

### ui-theme
月相主题自动切换、手动覆盖、底部导航、专注模式、生日祝福。
