方法列表:

[1] createTask(Map<String, Object> taskRequest)
  - 功能: 创建新任务
  - 输入: taskRequest (包含name, content, assigneeId/assigneeIds, isUrgent, startTime, endTime等字段)
  - 输出: ApiResponse<Map<String, Object>> 包含创建的任务ID和审批状态
  - 异常: 
    * BAD_REQUEST - 任务名称/正文为空或超长
    * FORBIDDEN - 无权限

  - 审计操作: TASK_CREATE

[2] listTasks(String status, Long assigneeId, Long dispatcherId, Boolean showCompleted, String keyword, String startDate, String endDate)
  - 功能: 获取任务列表（支持多条件筛选）
  - 输入: 可选参数 - status(状态), assigneeId(负责人ID), dispatcherId(创建人ID), showCompleted(是否显示已完成), keyword(关键词), startDate(开始日期), endDate(结束日期)
  - 输出: ApiResponse<List<Map<String, Object>>> 任务列表
  - 异常:
    * BAD_REQUEST - 任务状态无效
  - 边界条件:
    * status只能为"IN_PROGRESS"或"COMPLETED"
    * keyword为空时忽略搜索
    * 日期格式为"yyyy-MM-dd"

[3] getTask(Long taskId)
  - 功能: 获取单个任务详情
  - 输入: taskId - 任务ID
  - 输出: ApiResponse<Map<String, Object>> 任务详情

三、测试用例设计建议
================================================================================

--------------------------------------------------------------------------------
等价类划分建议:
--------------------------------------------------------------------------------

1. 任务管理模块:
   - 正常输入: 合法的任务名称(1-256字)、正文(1-5000字)、有效时间范围
   - 边界输入: 空名称/正文、超长名称/正文、截止时间等于开始时间、极值ID
   - 异常输入: 非法状态值、负数ID、不存在的ID、格式错误的日期字符串

2. 日志管理模块:
   - 正常输入: 有效日期、合理的工作内容、合法的完成状态
   - 边界输入: 空内容、超长内容、日期边界（月初/月末/闰年）
   - 异常输入: 不存在的日期、未来日期（超出可写范围）、非法完成状态

3. AI模块:
   - 正常输入: 有效的提示词、合法的MBTI答案列表(28题)
   - 边界输入: 空提示词、极短/极长文本、空答案列表
   - 异常输入: null值、格式错误的答案、不支持的分析类型

4. 占卜模块:
   - 正常输入: 有效日期、正整数(1-8191)、合法卦名(64卦)
   - 边界输入: 极小/极大数字、空卦名、动爻边界(1和6)
   - 异常输入: 负数、0、未知卦名、动爻超出范围

--------------------------------------------------------------------------------
边界值分析建议:
--------------------------------------------------------------------------------

1. 任务名称长度: 0, 1, 255, 256, 257
2. 任务正文长度: 0, 1, 4999, 5000, 5001
3. 时间范围: 开始时间=截止时间, 开始时间>截止时间, 开始时间<截止时间
4. ID范围: 0, 1, -1, Long.MAX_VALUE, Long.MIN_VALUE
5. 状态枚举: IN_PROGRESS, COMPLETED, 其他非法值
6. 日期格式: 正确格式、空字符串、null、格式错误字符串
7. 数字范围: 0, 1, 8191, 8192, 负数
8. 动爻范围: 0, 1, 6, 7
