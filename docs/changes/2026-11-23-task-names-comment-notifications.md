# 1.0.1：通讯录任务名称与日志评论通知

## 修复结果

通讯录进入下属任务页后，月视图下方“全部任务”读取原接口的 `NAME` 大写字段时，
卡片只访问 `name`，导致名称、状态、时间等信息丢失。
现在人员任务接口统一输出小写字段，Android 卡片同时兼容旧的大写响应，显示真实名称和任务信息。

上级评论日志后，在同一事务内为日志作者生成 `LOG_COMMENTED` 通知；
内容包含评论人、日志日期和评论摘要，使用独立 `log_id` 指向日志，避免误跳任务详情。
自评、越权或失败的评论不会留下通知。原有手机端隐藏的管理员评论仍不产生手机提醒。

设置增加“上级评论日志通知”，默认开启；关闭仅停止系统提醒，通知列表仍可查看记录。
通知列表分类、系统通知标题及点击跳转均已接入对应日志详情。
保存开关失败会回弹，程序初始化及回弹不会重复发出保存请求，新开关也支持键盘和辅助功能操作。

云端自动补齐通知表的可空 `log_id` 字段，兼容关闭 SQL 自动初始化的现有数据库。
后端已更新至实际服务；原通知、账号、关系、任务、日志及演示数据均保留。
