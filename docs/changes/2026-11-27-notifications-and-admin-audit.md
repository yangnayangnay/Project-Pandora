# 2026-11-27 未读通知、通知接收与管理员操作日志

## 排查与修正

- 首页铃铛原来没有读取未读状态。现在按账号缓存和查询服务端未读数，有未读显示红点；读屏描述含未读数量。查看通知列表不自动全部已读，点击记录或系统通知后标记对应记录，更新红点。
- 前台服务原来每15分钟才查询一次。现在使用经过认证的25秒异步等待：有新通知或未读数变化时即返回，正常返回后继续等待；失败重试，网络恢复唤醒重连。服务器每秒检查等待请求，不长期占用请求线程或数据库连接。前台界面15秒补查，WorkManager保留15分钟后台兜底。
- 原渠道为默认优先级，不保证横幅。新工作动态渠道默认高优先级，配置锁屏通知及长文本；尊重用户已关闭或手动调整的渠道级别。设置页显示系统通知、横幅和电池优化状态，并提供系统设置入口。
- 原接收游标与偏好跨账号共用，通知失败后仍推进游标。现在按账号隔离；已读和关闭提醒的记录可推进游标，未成功发送的提醒保留待重试。并发接收串行确认，防止较旧响应回退已处理游标。读取按ID升序分批，超前游标重置后补取，不丢掉批次尾部。
- 公司十大任务派发修改接口原来漏发变更通知，现已补齐。通知生成异常不再静默吞掉，服务端保留错误日志。
- 管理员日志默认类型过滤未包含人员操作。列表和导出现在包含入职创建、离职、交接、恢复、岗位调整、部门和团队管理等操作，新增中文标签和筛选。入职记录包含新账号工号和目标ID，不记录密码；离职和交接分别记录操作对象、接任人、任务接收人与任务数量，和业务操作同事务提交或回滚。失败操作不误记为成功。

## 生效范围和平台边界

后端和管理员网页可以独立更新；手机端红点、接收服务和通知渠道需要安装包含本次源码的新版本才能生效。本轮没有生成或安装APK，也没有进行真机息屏验收。

当前实现不是厂商推送。Android深度休眠、厂商后台限制、关闭通知、勿扰、强制停止，以及Android 15及以上dataSync前台服务时间额度，仍可能延迟或阻止系统弹窗；不能宣称任何手机任何状态下都实时弹出。若要求进程被系统终止后仍及时提醒，需要另外接入适配目标机型的厂商推送通道。本轮未配置这类外部服务。
