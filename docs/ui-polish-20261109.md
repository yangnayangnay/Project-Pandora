# 本轮 UI 修改记录

范围：Android 手机端与 Web 管理端，保留现有业务规则、权限和数据接口。

## 已落实的审查建议

- 完成情况绿色标签加深；白字对比度从 2.78:1 提升到 5.74:1。
- 补齐夜间主按钮悬停、按下颜色；文字和图标使用相同前景色。
- 任务明细筛选按横竖屏排列，完整展开，筛选内部无滚动区；整页可滚动，表格保留可操作高度。
- 任务表格列宽随可用宽度和字号调整，六列共用同一宽度定义；空间不足时显示横向滑动提示。
- 任务筛选收起后仍显示已生效条件摘要；日期选择弹窗提供清除操作。
- 人员详情采用可滚动资料卡，拆分姓名、联系方式、组织资料和签名，保留任务、日志入口。
- 人员选择模式使用勾选框，通讯录浏览模式使用进入箭头；选中说明同步更新。
- 搜索姓名、账号、团队或部门后直接显示匹配人员，搜索仍限于原接口返回的权限范围。
- 普通导航栏统一为 56dp；统一内容起点与返回图标风格。
- 首页副标题减少无效高度，给事件和任务正文留出空间，三个分区标题保持 20sp。
- 首页磨砂卡片取消顶部额外描边线，改为单次等宽、内缩圆角描边；保留内部渐变高光和柔和投影。
- 任务详情明确快捷调整与底部修改的区别，修改按钮降为次要按钮，正文放大到 16sp。
- 多负责人按钮显示已选人数，姓名改为下方可换行标签。
- 日志与任务筛选统一字号、白色控件框和日期选择器；筛选摘要在收起后可见。
- 区分无数据、筛选无结果与加载失败；刷新失败保留已有任务、日志，提供重试入口。
- “我的”减少多层重复留白，文本箭头替换为主题适配的线性图标；个人资料标签统一层级。
- 管理端统一暖色主题、日夜配色、标题、圆角、交互反馈及窄窗口布局。
- 部门、团队成员先显示三人，其余展开查看，职级名称中文化；部门和团队编辑弹窗统一规格。

## 日历字号与分区

- 月历星期 14sp、日期 26sp、农历 12sp，事项/任务条 13sp；周任务 14sp、日任务 16sp。
- 两种月历每个日期显示最多五个条目，另留一行显示超出数量；达到五项时五项均可见。
- 日期格随系统字号增高；条目高度、间距、点击区域和弹出位置采用一致尺寸。
- 保留七列日期、跨日条目和跨周切分；文字裁剪于自身区域。
- 字号增大通过提高日期格高度实现，完整月历需要纵向滚动。
- 月历任务文字与背景使用配对的日夜颜色；计算得到最低对比度：白天 4.73:1、夜间 4.76:1。
