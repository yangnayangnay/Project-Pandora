# 2026-11-23 事项与人员关系云端修复

本次已更新手机端和管理端实际连接的云服务器 `123.56.153.138`，同时更新本地源码。未生成、复制或安装 APK。

## 实际故障原因

- 云端日志反复报 `Column "START_CLOCK" not found`。线上关闭了自动 SQL 初始化，
  更新后端文件没有自动执行本地建表脚本，导致事项读取和创建失败。
- 上一轮仅修改了本地项目，云端仍运行 SHA-256 为
  `dab3a1c00f245ff64f517e7fbc0109da8527081b8d55710bd727b0acbe28ebd4` 的旧后端，
  尚无新增的统一关系读取和启动修复逻辑，旧的管理员及同级关系仍会显示。

## 已发布修复

- 事项启动升级独立于 `spring.sql.init.mode`，按实际表结构补齐日期、时间字段；
  只对缺少的字段执行添加，按原事项日期回填空的范围日期，可重复运行。
- 服务启动及岗位调整事务校正旧关系；人员总表、组织视图和手机关系接口均使用按已批准岗位计算的关系。
  同级创始人不互为上下级，管理员不参与组织，部门负责人直属全部创始人。
- 管理端保存关系时，等待旧的加载请求完成后再重新读取，避免旧响应覆盖保存结果。
  页面返回前台和可见期间每 15 秒刷新；手机端源码也增加前台定时刷新及返回刷新。
  手机源码变更未打包到设备，现有客户端重新进入页面会使用已修复的云端接口。
- 创建账号的姓名、密码、身份证校验同步部署，退休年龄按用户确认的未满 60 周岁处理。
- 统一后端测试库为实际应用结构，补齐标签及任务变更字段，并为测试配置补齐离职服务依赖。
