# Pandora Android 视觉规范

本文记录 Android 原生界面的视觉规范及后续已批准的功能修订。各轮实现和验证范围分别记录在下方。

## 配色

| 用途 | 浅色主题 | 资源 |
| --- | --- | --- |
| 内容区 | 白色 `#FFFFFF` | `color_surface` |
| 页面底层 | 米白 `#F8F6F2` | `color_bg_page` |
| 次级容器 | 柔米色 `#F3EFE8` | `color_surface_soft` |
| 主操作、选中状态 | 可可棕 `#725B49` | `color_accent` |
| 正文 | 深棕灰 `#2C2823` | `color_text_primary` |
| 辅助信息 | 暖灰 `#756D63` | `color_text_secondary` |
| 分隔与轮廓 | 浅米灰 `#E9E3DA` | `color_divider` |

全局成功、待处理、错误提示使用对应状态色，同时保留文字说明。月视图日期格内的任务条、月视图下方列表，以及周、日视图的任务底色共用浅黄、珊瑚、紫、蓝、绿、杏、青绿、粉红八色调色板。引用标签的任务统一使用第一个标签的颜色，标签胶囊使用相同颜色；月视图列表中带标签的卡片主体同步着色。没有标签时继续按任务名称取色，列表卡片主体保持原有表面色。日期格本身不因标签变色。深色主题保留同色相深底，任务文字统一使用主题文字色。

首页上方“事件纪”和“任务看板”采用白色卡片、18dp 圆角、1dp 细描边和 1dp 阴影，外边距12dp、卡片间距8dp。左右标题栏分别保留浅杏色、鼠尾草绿及对应夜间配色；下方使用个人每日事项月历，具体交互见文末修订。

## 组件

- 白色工具栏、深色标题、统一线性图标；页面不再依赖大块品牌色划分层次。
- 卡片采用轻描边与约 18dp 圆角，表单使用约 12dp 圆角；导图分区、浮层和按钮通过柔和阴影区分层级。
- 系统中文字体，标题使用中等字重，正文以清晰和稳定为先。保留已约定的月、周、日任务字号。
- 主操作使用可可棕，次操作使用描边或文字样式，点击与选中反馈由原生控件提供。
- 通过 8dp 的间距节奏、内容对齐和留白区分信息，不增加装饰性动画。

## 验证与预览

使用 `:app:compileDebugJavaWithJavac` 检查 Java 和资源，不运行 APK 打包或安装任务。检查 XML 控件 ID、输入约束、可见性、选中状态，以及 Java 改动范围，确保纯视觉改动。

本轮已检查 48 个布局中的 389 个命名控件，控件 ID、类型、输入约束、可见性、默认选中值和交互标志与修改前一致。113 个资源 XML 全部解析通过；浅色与深色主题的正文、辅助文字、主按钮及三类状态提示，共 14 组配色的计算对比度均高于 4.5:1。Java 差异已核对，限于颜色资源、头像占位图及任务卡片描边和圆角。登录页新增滚动容器，保留全部原始子控件与属性，便于小屏查看完整表单。这些静态检查不能代替运行时功能验收。

在 Android Studio 打开实际布局或 `preview_schedule_month.xml`、`preview_schedule_week.xml`、`preview_schedule_day.xml`，选择 `Theme.Project_Pandora` 查看布局预览。样例只用于布局预览，不能代替更新后的应用在模拟器中的视觉和手势验收。

本轮未实际查看 Android Studio 或模拟器的渲染结果。操作步骤见 [Android Studio 预览指南](ANDROID_UI_PREVIEW.md)。

### 月历多色与导图卡片修订

月历的独立多色色板与导图标题配色分别提供浅色、深色版本，共 24 组前景/背景配对，按 4.5:1 的最低文字对比度检查。月历 Java 改动仅替换两处色板资源引用；导图保留节点类型、结构、文本和所有非视觉属性。资源 XML 总数随本次新增由 113 增至 118。实际阴影和小屏换行仍需在 Android Studio 或设备上查看。

### 任务颜色统一与完整日时间轴

月、周、日视图共享 `calendar_month_detail_colors` 和配对文字色，月视图列表色块采用相同取色规则。日时间轴在 `onMeasure` 中固定实际测量高度为 24 个小时行高加末尾留白，避免 `ScrollView` 的无约束测量使 `FrameLayout` 按最后一个任务收缩。无任务、只有上午任务、深夜任务、全天任务或切换至空日期时，均应可滚动查看 00:00 至 24:00。

本次主源码和 Android 测试源码编译通过。Gradle 的测试 worker 因入口类加载问题未启动，改用本机 JDK 的 `JUnitCore` 直接运行同一组已编译测试类，66 项单元测试全部通过。新增 `TaskScheduleTimelineTest` 包含上述 5 种真实 View 测量和滚动范围回归场景，已编译但未在设备上运行；本次未生成或安装 APK。

### 2026-11-04 首页交互与事项弹窗修订

新增和编辑事项共用圆角弹窗，参考公司任务创建页的18dp描边分组卡片、12dp圆角输入框、日期选择行和主按钮。保留500字限制并显示字数，内容必填；保存期间禁用重复操作，失败后保留文字及日期并显示错误；编辑时保留删除确认。弹窗可滚动，宽度适应手机和横屏，浅色与深色均使用既有主题语义色。
