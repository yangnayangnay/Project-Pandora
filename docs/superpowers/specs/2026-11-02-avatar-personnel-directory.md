# 头像修复与人员目录一致性

用户要求修复“我的”头像相册选择、拍照，并让人员关系参照新的他人日志选人界面，两处同步优化。补充要求：头像上传上限 5MB。全部由 Codex 直接完成，禁止生成、打包、安装 APK。

- 使用系统照片选择器（旧系统使用 AndroidX 内置文档选择回退），不请求广泛存储权限；拍照采用 Activity Result、相机权限、FileProvider URI 读写授权。拍照临时文件使用唯一名称，保存等待相机返回的路径，支持页面重建；取消不上传。
- 在后台采样解码、矫正 EXIF 方向、限制头像边长并编码为真实 JPEG；上传时显示处理状态、拦截重复点击，成功或失败清理临时文件。上传文件上限 5×1024×1024 字节，客户端提示与服务端业务校验一致；multipart 单文件 5MB、请求 6MB，为边界和字段保留空间。
- 修正头像的服务端绝对存储路径和配置目录映射；文件名使用 UUID 避免覆盖及图片缓存陈旧。个人资料和“我的”使用一致的头像 URL 规则。
- 日志选人和人员关系复用部门分组、搜索、卡片、返回路径、加载/空/失败重试状态。根层搜索可匹配部门、姓名、账号、小组；进入部门后继续精确搜索，返回保留根层搜索词。
- 人员关系展示当前账号有权获取的上级/下级，可切换全部、上级、下级；人员详情保留职务、部门、小组、直接/间接层级信息。日志选人保留全部、部门全部和单人选择，取消不修改筛选。
- 兼容关系接口旧版驼峰字段和仅返回部门名的情况；新版关系接口补充账号、部门及小组编号，不扩大查询范围。
- 使用前后端自动化测试验证 5MB 边界、文件保存与访问、关系数据、两种字段风格与组织搜索；Android 只编译主源码、测试源码和运行 JVM 测试。先检查 Gradle 任务图，不运行 APK 或设备测试，不部署服务器。
