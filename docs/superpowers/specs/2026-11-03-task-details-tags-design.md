# 任务明细和任务标签

用户于 2026-11-03 确认交互方案；标签管理仅限 FOUNDER，ADMIN 和其他角色只能引用。全部工作由 Codex 直接完成。

## 任务明细

- Android 视图页顶部增加“任务明细”按钮，月、周、日模式均可进入独立页面。
- 默认展示本人负责或本人布置的所有任务，按 ID 去重，不受当前选中日期限制。提供全部相关、我负责的、我布置的三个范围。
- 简约表格支持横向滚动查看任务名称、正文、标签、状态、优先级、重要性、紧急程度、负责人、布置人、开始时间、截止时间、进度说明、创建时间和更新时间；点击行进入原有任务详情。
- 筛选包含关键词、范围、状态、负责人、起止日期、标签，条件同时生效，可一键重置，显示结果数量。日期按任务覆盖区间与筛选区间相交计算，沿用跨日及结束于次日零点的现有规则。
- 空结果、请求失败、加载中分别展示；返回页面刷新服务器数据并保留当前筛选。本人布置给本人的任务在两个单独范围内都应出现。

## 标签和权限

- 创建任务增加 #标签 搜索与多选，输入支持 # 和全角＃；只能引用已有标签。展示有序的已选标签，可移除、前移；第一个标签标注为主色。
- 任务详情展示标签，并允许原有可编辑任务角色调整引用和顺序。该修改经过原有任务审核，不能绕过上级审核。
- FOUNDER 可通过标签管理页新增、改名、删除和选择颜色；其他角色包括 ADMIN 无管理入口，服务端仍独立校验 FOUNDER，拒绝伪造请求。
- 标签名称去除前导 #、去首尾空白，禁止空名称、重复名称（忽略大小写）、内部空白或 #，最长 32 字。每项任务最多引用 10 个不同标签，保持用户选择顺序。
- 颜色复用现有八色调色板：黄、珊瑚、紫、蓝、绿、杏、青绿、粉；深色主题使用同色系深色版本。标签色与任务背景在同一主题内保持一致，文字沿用主题文字色。
- 标签改名、改色会影响全部引用任务；删除标签后不再展示或允许引用，首个标签被删除时顺延到下一个，没有标签时沿用原任务名称取色。
- 颜色用于月视图日期下方的任务条、周和日视图的全天任务及时间任务块；日期格本身不变。月视图下方任务列表同步展示标签及主色。
- 草稿和页面重建保存标签选择及顺序；已删除的草稿标签明确提示并移除，不静默提交失效标签。

## 数据和集成

- 新增标签表和带排序的任务标签关联表，使用独立 ID 引用。任务请求只提交有序 tagIds，不接受客户端提交标签定义或颜色。
- 后端统一服务负责标签权限、校验、引用存储和批量附加任务标签；任务列表、详情、四象限及下属任务返回有序 tags 数组。
- 将 tagIds 纳入 TaskChangeService 的创建、编辑和审核流程，提交与批准时均校验有效性；待审期间标签被删除时明确阻止批准，退回后重新申请。
- 创建/替换任务引用与任务写入处于同一事务；不提交 tagIds 的旧客户端保持原有标签，不因编辑其他字段清空标签。
- 新任务明细复用现有按本人负责和本人布置查询的接口，不调用无范围的全公司任务列表。
- 保留已有工作区修改，不重写相关模块；本次不扩展 Web 管理端，不部署服务器。
