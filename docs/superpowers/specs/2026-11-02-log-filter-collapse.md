# 日志筛选栏收起与展开

用户要求在筛选栏下方增加收起入口，并明确使用小箭头，不显示按钮文字。

- 默认展开筛选栏，下方居中显示朝上小箭头；点击后隐藏整个筛选卡片，为日志列表腾出空间，入口变为朝下箭头，再次点击恢复筛选栏。
- 图标尺寸为 24dp，点击区域为 48dp；提供随状态变化的无障碍操作说明。
- 用户补充：箭头底色为白色半圆，与筛选栏接壤。采用 48×24dp 的下半圆，直边向上，与筛选卡片底边重叠 1dp 消除边框接缝；箭头居中，保持深色以适配白色底。剩余点击区域透明，保留 48dp 触控高度，点击反馈裁切在半圆内。
- 切换状态只旋转箭头图案，半圆始终保持直边朝上，避免整个按钮旋转导致底色翻转或脱离筛选栏。
- 用户补充半圆周围的柔和阴影：使用 4dp 系统投影，投影轮廓与白色下半圆一致，排除下方透明触控区域，避免产生方形阴影；半圆与筛选栏保持贴合。
- 收起/展开只改变可见性，不清空筛选输入或重新查询。我的日志/他人日志共用此状态，并在页面重建时恢复。
- 收起时清除关键词输入焦点并隐藏键盘，避免隐藏筛选栏后键盘继续占用日志列表空间。
- 本次仅修改客户端；由 Codex 直接完成，不委派、不打包或安装 APK。
