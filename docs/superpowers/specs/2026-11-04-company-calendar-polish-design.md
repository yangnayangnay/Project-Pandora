# 公司页任务详情与日期导航修订

本轮按用户列出的公司页修改要求执行。本地修改与验证，不部署服务器，不生成、复制或安装 APK。用户已授权由 Codex 完成设计、实现和最终复核；按后来提供的分工要求，机械检查可交给本地 DeepSeek Harness，最终结果仍由 Codex 核对。

## 已核对的问题与方案

1. 标签选择器的提示行无条件绑定 reload，导致点击“点击标签引用”重新请求并闪烁。提示行统一为不可点击、不可聚焦的文字；加载失败另显示明确的“重试”按钮。已有标签仍可点选、删除和调整主色顺序。
2. 截图对应 TaskDetailActivity 顶部的五列表头和数据行。删除整块表格，改为独立任务标题及负责人文字；截止时间、完成状态和紧急程度继续由详情已有区域表达，避免重复与截断。
3. 删除详情中的“退回”入口及其事件绑定。保留原权限和开始、完成、切回未完成、确认、删除操作；底部所有可见按钮等宽、同高、同内边距，长文案保持单行。
4. 橙色块读取旧 priority 枚举（LOW/MEDIUM/HIGH/URGENT），并非由 is_important/is_urgent 统一计算。当前手机创建任务仅填 URGENT 或 MEDIUM，历史数据仍可能为 HIGH/LOW。选择删除详情中的冗余优先级块，保留真实重要/紧急象限、状态和调整入口，不改后台存储字段。

## 日期导航

对比继续使用逐月日历、系统年份列表和年月日直接选择：采用年月日三列原生 NumberPicker，可滚动或点数字输入年份、月份、日期；相比逐月翻页可直接跳转，相比仅年份列表可一次完成精确定位。保留取消、今天和确定，只有确定才提交；更改年月时日期按当月有效天数收敛，覆盖闰年和月末。

公司页展开、普通和收起的月历支持左滑下一月、右滑上一月；周、日视图分别移动一周、一天。保留可见前后箭头和今天，左右手势不切换视图类型。共享手势方向锁定，横向位移明确越过阈值才翻页；一次手势仅一次切换，禁止滑动后误触任务，多指及取消不翻页；纵向滑动继续用于列表滚动及月历展开收起。系统返回边缘不主动屏蔽。

年月日弹窗共用当前 selectedDate；月/周/日切换继承同一日期。月末翻月按 Calendar 的有效日期收敛，保持已有选中日，避免固定重置为1号。浅色、深色沿用既有语义颜色、字体及圆角。
