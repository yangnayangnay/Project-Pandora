# 日历视图交互修复方案

状态：用户已于 2026-11-02 确认采用推荐方案；已实现并完成下述验证。

## 目标和范围

修复 Android「视图」页的四个问题：月历四项任务展示和溢出弹窗、点击大日期跳转、选中日期与任务列表联动、任务文字不随任务背景配色变化。保留当前已有的月历连续跨日色条、月/周/日切换和任务权限逻辑。

## 建议交互

### 月历四项展示和当日任务弹窗

- 月历展开显示任务时，每天最多直接展示四项；第五项起显示「+N项」，N 为当天未直接展示的项数。
- 恰好四项时四项都显示，不因同周其他日期任务较多而提前折叠。跨日任务继续按覆盖日期显示，并尽量保持连续色条。
- 行高保证四条任务和一条溢出提示有独立空间；小屏幕和六行月份允许纵向滚动，避免任务被裁切。
- 当某日有五项及以上任务时，点击该日的日期、空白区域、任务条或溢出提示，先选中该日，再弹出当日全部任务。
- 弹窗标题显示选中日期和星期，列表显示任务名称及时间，内容可滚动；点击一项才进入该任务详情。关闭弹窗保留选中日期。
- 四项及以下时，点击日期更新选中日，点击任务条仍可直接进入该任务详情。

### 大日期点击跳转

- 点击月视图展开或收起状态下的大月份标题，打开系统日期选择器，初始值为当前选中日期。
- 周视图和日视图的大月份标题使用相同交互，避免切换视图后入口行为不一致。
- 确认后跳转到所选年月日，更新当前视图和相关日期标题；取消时保持原日期。保留翻月/翻周/翻日与「今天」按钮。

### 当日任务列表

- 月视图下方详情/列表区域按选中日期筛选，再应用「全部任务 / 我的任务 / 我布置的任务」范围。
- 列表标题包含选中日期及条数，空状态为「当天暂无任务」。点击日期、翻月、回到今天或通过选择器跳转时，同步刷新列表。
- 日期覆盖规则复用现有 MonthTaskDates：跨日任务在覆盖的各日出现；结束时间为次日零点的计时任务不额外占用次日；无日期任务不进入当日列表。
- 月历弹窗与下方列表共用日期筛选规则，避免同一天出现不同的任务集合。
- 周视图继续展示本周任务，日视图继续展示当日时间线；不改变两种视图的用途。

### 固定任务文字颜色

- 月、周、日视图中的任务名称和任务卡片时间统一使用主题的主要文字色，取消按任务背景色索引匹配不同文字颜色的做法。
- 同一主题内，无论任务背景色如何变化，文字颜色均相同；浅色主题使用深色文字，深色主题使用浅色文字，保留可读性。
- 保留任务背景色和列表左侧色条；状态徽标仍表达原有状态。

## 方案比较

推荐复用系统日期选择器和原生可滚动当日任务弹窗：改动集中，适配现有 Android 页面，便于验证返回和取消行为。

另一方案是自定义年月日滚轮与浮层，可更接近参考图外观，但会增加布局、触摸区域和深色主题适配工作，本次无需引入。

## 实现边界

- ViewFragment 维护统一的选中日期，负责标题点击、日期选择器、当天任务弹窗及列表刷新。
- PhoneMonthView 负责四项展示、准确的溢出计数和点击日期/任务路由；MonthTaskLayout 的调整仅服务于连续任务排布及每日展示保证。
- TaskScheduleView 接入标题选日和统一文字色；复用既有任务详情跳转。
- 保留工作区现有未提交改动，只修改本次涉及的 Android 文件；不调整后端接口和 Web 管理端。

## 验收

1. 验证四项完整显示，五项/更多任务显示准确溢出数量，弹窗可查看全部且逐项跳转。
2. 验证跨日、跨周、六行月份及小屏幕不丢失第四项，不因同周其他日期溢出而误折叠。
3. 验证大日期标题可选日，确认跳转、取消、翻页和今天按钮行为正确。
4. 验证选中日期、三个任务范围和空状态联动，跨日/零点边界与月历一致。
5. 验证不同任务背景下文字色一致，以及浅色和深色主题可读性。
6. 运行相关 JVM 回归测试、Android 编译和可用的设备界面测试；缺少设备时明确区分已执行和未执行的检查。
