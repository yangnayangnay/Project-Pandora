# 安卓账号资料只读

按用户要求，安卓用户不能自行修改真实姓名、邮箱、工号、手机号或密码。本轮由Codex直接实现与验证，不生成或安装APK，不部署服务器。

## 页面与接口

- 个人信息页将四项资料改为带标签的静态文字，沿用现有卡片、字号和主题颜色，显示“由管理员统一维护，如需变更请联系管理员”。删除资料保存按钮、请求和表单校验。头像保持独立即时上传及原有压缩、缓存行为。
- 删除安卓修改密码入口、Activity、布局和清单注册，移除安卓UserApi中的资料修改与密码修改方法；不展示密码值。忘记密码仍为重置申请，由管理员处理，不允许用户自行指定新密码。
- 服务端依据数据库中的角色判断权限：现有登录规则仅允许非ADMIN业务角色登录APP，ADMIN登录WEB。非ADMIN对`PUT /user/me`只能提交头像字段，其他字段（包括空值及别名）均返回403，必须在任何写入前拒绝；`PUT /user/me/password`对非ADMIN直接返回403。沿用现有管理员Web资料和密码维护接口及校验，不信任请求中自报的客户端或角色。
- 不更改头像上传、个人设置、生日及管理员管理其他账号的权限。
