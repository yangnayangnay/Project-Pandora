- 使用管理员专用 `PUT /user/{id}/profile`。只允许上述六个字段，前端只发送变更项；工号保持字符串及前导零。历史空值或旧格式资料未修改时保留，修改后的字段按创建账号规则验证，必填资料不能主动清空。

- 此接口不修改密码、头像、组织关系或安卓用户的自行维护限制。保存成功更新列表及已打开的资料；失败保留输入。修改自己的账号时更新管理端本地姓名和工号显示。
- 回归覆盖全部资料落库、旧工号失效/新工号登录、前导零、本人不误判重复、无效及重复字段无部分写入、历史空资料、权限及字段白名单。运行后端测试、前端测试及 Web 构建；不使用生产账号或生产数据库。
