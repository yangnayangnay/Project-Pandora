# 日志日期、组织筛选与上级评论

用户确认：全部工作由 Codex 完成，不委派 DeepSeek；不生成 APK。快捷日期由用户澄清为「前天 / 昨天 / 今天」。

- 客户端、服务端创建/编辑以及离线重放统一允许上海时区的前天至今天，保留每人每天一篇日志的唯一约束。
- 加号始终打开日期可选的新建页；已选日期有日志时，提示打开独立编辑页，返回后仍可选择其他日期。真实编辑页保留日志原日期，避免把已有日志搬到别的日期。
- 他人日志使用独立的两步选择页：部门 → 人员；可以查看一个部门内全部有权限人员，或搜索姓名、账号、小组选择个人。保留全部人员、未分配部门、筛选重置与取消返回。
- 服务端只返回既有上下级授权范围内的人员组织标签，部门筛选不能扩大权限。
- 日志详情显示持久化评论、评论者和时间；有评论权限的上级可提交不超过 2000 字的非空评论，作者可阅读。评论不受日志编辑日期范围限制。
- 评论每次读写均以数据库当前关系校验；评论者必须职级更高且具有现有下属授权。员工不能评论、不能自评、不能跨授权范围访问。管理员/创始人沿用系统现有全局查看权限，但查看同级日志不代表有评论权限；前端根据服务端返回的 canComment 显示输入框。
- 不增加回复、删除评论或通知等未请求的功能。仅修改本次日志相关路径，保留既有其他工作区改动。

验证：Android 源码/测试源码编译、JVM 日期和组织搜索回归、后端内存数据库评论权限及部门筛选测试。先检查 Gradle 任务图，不执行 APK 打包/安装或依赖测试 APK 的设备测试。
