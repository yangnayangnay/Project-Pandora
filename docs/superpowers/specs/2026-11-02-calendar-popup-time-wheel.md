# 日历任务浮层与滚轮时间选择

依据：用户于 2026-11-02 提供的两张参考图和明确交互要求。本方案更新此前日历方案中的点击与弹窗规则。

## 交互与实现

- 点击月历日期、空白处或收起态日期条，只选中日期并刷新下方任务面板，无论当日任务数量多少，均不打开浮层。
- 点击展开月历中日期下方的任务条或「+N项」，选中对应日期并打开当天完整任务浮层；一至四项也使用同一交互。
- 浮层采用参考图一的圆角、轻阴影、靠近点击位置的布局，显示月日星期、完整农历、左侧浅蓝标记和任务名、右侧分行起止时间。长列表可滚动，长名称可换行；跨日时间包含月日。
- 点击浮层中的任务进入既有详情页；点击外部或返回键关闭。关闭保留选中日期，页面销毁时释放浮层。
- 创建任务保留日期选择，随后使用参考图二的小时、分钟两列滚轮：24 小时、两位数字、循环滚动、中央圆角选中带、橙色选中数字与时间预览，提供取消和确定。
- 开始、结束时间共用滚轮；以当前值初始化。仅确定时更新表单及草稿，取消、返回或点击外部不写入部分选择。保留原有开始/结束先后校验。
- 使用现有浅深色语义色板；短横屏减少滚轮可见行数，保证底部操作可见。
