# 日历视图实施清单

依据：用户已确认的 2026-11-02-calendar-view-design.md。当前环境没有提供 writing-plans 技能文件，使用本清单组织实施和验证。

1. 复用日期覆盖规则，新增不依赖 Android 的当日任务筛选入口，供日历和下方列表共同使用。
2. 在现有跨日排布之上增加每日四条可见排布，继续优先保持跨日任务所在行；当日空行可补入先前隐藏任务，确保四项以下不被同周拥挤日期影响。
3. 月历展开时提供足够的最小行高及纵向滚动；点击路由先确定日期，五项以上优先打开当日列表，其他任务条保留直接跳转。
4. Fragment 统一处理月份标题日期选择、当日列表刷新、可滚动任务弹窗与生命周期清理。
5. 让 DeepSeek Harness 执行已明确的周/日标题入口、文字色和 XML 包装修改；Codex 审查实际差异。
6. 补充每日四条、第五条折叠、拥挤日期后恢复展示、跨周任务、日期筛选及点击路由的回归检查。机械测试编写和既有构建检查交由 Harness。
7. 用现有 JDK/Gradle/Android SDK 运行相关单元测试、Android 编译及可用的设备测试；若 Harness 命令沙箱失败，记录具体错误，再由 Codex 执行已授权检查。

仅处理本次 Android 日历需求，保留当前工作区其他未提交改动。
