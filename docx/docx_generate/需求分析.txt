一、项目背景
================================================================================
某公司因发展需要，计划构建一个高效的任务分发、信息收集和数据分析系统，
内部项目代号为 Project: Pandora，目标为帮助公司管理层及员工实时掌握
个人与团队工作情况。

系统需要搭建：
  1. Android 移动端 App（主要面向员工使用）
  2. Web 管理端（主要面向管理层使用）

================================================================================
二、6 个 Epic 分组
================================================================================
Epic-1: 任务管理闭环
  - 涵盖任务的创建、分发、接收、进度更新、确认完成等全生命周期管理
  - 支持 6 项核心指标：任务名称、优先级、完成情况、任务时间节点、进度说明、责任人
  - 四象限任务管理（重要紧急/重要不紧急/紧急不重要/不重要不紧急）

Epic-2: 日志管理闭环
  - 工作日志的录入、查询、统计、编辑
  - 十大重要工作编辑与展示
  - 日志统计图表（完成率表格/重要占比饼图/分析竖图）
  - 晨星冒烟测试（每天首次进入日志页执行轻量级完整性校验）

Epic-3: 视图展示闭环
  - 月视图、周视图、日视图切换展示
  - 导图页四大板块（公司10大重要/公司派发10大/个人10大重要/个人日志）
  - 信息数据地图可视化

Epic-4: AI 智能分析闭环
  - MBTI 职业性格测试（16种性格类型，生成职业分析评测报告）
  - 关键词提取与重要程度排序
  - 个性化工作建议与职业发展报告
  - AI 信息地图（公司走向+个人方向分析）
  - 每日占卜（基于梅花易数规则，纯本地计算）[扩展功能]

Epic-5: 角色权限闭环
  - 5 种角色层级：管理员、创始人、部门老总、团队长、员工
  - 信息穿透鉴权（不同角色查看不同范围的数据）
  - 信息邀约请示机制
  - 分层审核规则配置

Epic-6: 界面与主题闭环
  - 月相主题自动切换（8种月相主题：新月/蛾眉月/上弦月/盈凸月/满月/亏凸月/下弦月/残月）
  - 手动主题选择覆盖自动切换
  - 底部导航栏 5 项（导图/视图/日志/AI地图/我的）
  - 卡通快乐风格界面设计

三、25 个 User Story 摘要
================================================================================
[US-001] 员工创建个人任务 - 员工登录后填写任务信息创建个人任务，任务出现在个人列表
[US-002] 上级分发任务 - 上级填写完整6项指标分发任务给责任人
[US-003] 员工接收任务通知 - 任务分发后员工收到通知且任务出现在"待接收"列表
[US-004] 员工更新进度标记完成 - 员工更新进度并标记"已完成"，上级收到待确认通知，晨星冒烟测试校验通过
[US-005] 上级确认任务完成 - 上级确认任务完成，状态变为"已确认"流程结束
[US-006] 四象限视图切换 - 用户切换四象限视图，任务按四类展示

[US-007] 员工录入日志 - 员工填写日志提交，保存成功并出现在个人日志列表
[US-008] 员工查看日志列表 - 员工查看个人日志列表，按时间倒序展示
[US-009] 日志统计图表 - 用户进入日志统计页，展示完成率表格/饼图/竖图三类图表
[US-010] 晨星冒烟测试 - 当天首次进入日志页执行晨星冒烟测试，校验通过后正常展示
[US-011] 十大重要工作编辑 - 员工编辑个人10大重要工作保存成功并在导图页展示

[US-012] 月/周/日视图切换 - 用户点击月/周/日视图标签，展示对应时间维度工作任务
[US-013] 导图页四大板块 - 用户进入导图页，同时展示四大板块内容
[US-014] 信息数据地图 - 用户查看信息数据地图，展示可视化地图

[US-015] MBTI性格测试 - 用户完成MBTI测试答题，系统生成对应性格类型的职业分析评测报告
[US-016] 关键词分析 - 用户触发关键词分析，展示提取的关键词及重要程度排序
[US-017] AI个性化建议 - 用户查看AI建议，展示基于个人数据的个性化工作建议和职业发展报告
[US-018] AI信息地图 - 用户查看AI信息地图，展示公司走向分析和个人方向分析的可视化地图
[US-019] 每日占卜 - 用户查看每日占卜，展示基于梅花易数规则的当日工作宜忌参考

[US-020] 创始人穿透查看 - 创始人查看任意员工面板，展示该员工完整工作信息
[US-021] 部门老总穿透与邀约 - 部门老总查看下属面板展示下属工作信息，发起信息邀约请示上级收到请示
[US-022] 分层审核规则配置 - 管理员配置分层审核规则，后续任务分发按规则触发审核流程

[US-023] 月相主题自动切换 - 系统检测到月相变化自动应用对应月相主题，切换平滑无闪烁
[US-024] 手动主题选择 - 用户手动选择某主题，界面应用用户选择的主题并覆盖自动切换
[US-025] 底部导航栏 - 用户查看底部导航栏，展示导图/视图/日志/AI地图/我的5个导航项，点击可切换页面

四、5 种角色定义
================================================================================
1. 管理员（ADMIN）
   - 全量修改系统信息的能力
   - 建立分层审核，信息修改后由分层审核进行复核
   - 可配置审核规则、管理用户/部门/团队

2. 创始人（FOUNDER）
   - 全量穿透进入所有智能面板
   - 具有全量收集分发功能
   - 做好公司整体信息查看功能

3. 部门老总（DEPT_HEAD）
   - 基础功能＋向下信息穿透查看
   - 要向上级形成信息邀约请示

4. 团队长（TEAM_LEADER）
   - 基础功能＋向下信息穿透查看
   - 向上级形成信息邀约请示

5. 员工（EMPLOYEE）
   - 基础面板功能，仅查看自己信息
   - 个人面板类似于人人网个人面板

五、技术栈选型理由
================================================================================
【Android 端】
  - 语言: Java（用户偏好，熟悉Java开发）
  - 架构: MVVM + Repository（Google推荐架构，清晰的数据流）
  - 依赖注入: Hilt（Google官方DI框架，编译时检查）
  - 网络: Retrofit 2 + OkHttp 3（Android最成熟的网络框架）
  - 本地存储: Room（Jetpack官方ORM，编译时SQL检查）
  - 响应式: RxJava 3（处理异步数据流，与Room/Retrofit无缝集成）
  - 图表: MPAndroidChart（成熟的Android图表库，支持饼图/柱状图/折线图）
  - 加密存储: Security-Crypto（EncryptedSharedPreferences，安全存储Token）
  - 图片加载: Glide（高效的图片加载和缓存）

【后端】
  - 框架: Spring Boot 3 + Java 17（企业级框架，生态成熟）
  - 数据库: MySQL 8.0（关系型数据库，支持JSON字段）
  - 缓存: Redis 7（会话管理、限流、缓存）
  - 认证: JWT（无状态认证，适合移动端）
  - AI接入: deepseek API代理（密钥不暴露给前端）

【Web 管理端】
  - 框架: Vue 3 + Vite（现代前端框架，快速构建）
  - UI库: Element Plus（企业级Vue3组件库）
  - 状态管理: Pinia（Vue3官方推荐状态管理）
  - 图表: ECharts（功能丰富的可视化库）

【启动方式】
  - run-server.bat（Windows批处理文件，符合用户偏好）

================================================================================
六、非功能需求（2项已选定落实）
================================================================================
NFR-1: 月相主题自动切换
  - 系统应支持根据当天月相自动切换界面主题
  - 8种月相主题：新月/蛾眉月/上弦月/盈凸月/满月/亏凸月/下弦月/残月
  - 切换平滑无闪烁，使用过渡动画
  - 支持手动模式覆盖自动切换

NFR-2: 本地日志管理
  - 完善日志模块，注意本地保存和定时或者定量清除日志
  - 日志写入应用私有目录按日分文件
  - 敏感信息过滤（password/token/手机号等）
  - 总量超过50MB或存在超过7天的文件时自动清理

================================================================================
七、验收核心功能（3项）
================================================================================
1. 创建任务 - 任务创建表单，6项核心指标必填校验
2. 日历视图 - 月/周/日视图切换，借鉴番茄计划
3. MBTI分析 - 16型性格职业分析评测报告

================================================================================
八、扩展功能
================================================================================
每日占卜（基于梅花易数规则）
  - 以时间起卦：年支数+月数+日数取上卦，加时支数取下卦
  - 动爻由总和取余
  - 得到本卦/互卦/变卦
  - 映射为工作宜忌语义（宜：规划/沟通；忌：冲动决策）
  - 输出：本卦名/变卦名/宜/忌/运势等级/趣味文案
  - 纯本地计算无需调用AI

================================================================================
九、界面设计要求
================================================================================
- 卡通风格，快乐风格
- 参考番茄计划的月视图、周视图功能
- 四象限任务管理（重要紧急/重要不紧急/紧急不重要/不重要不紧急）
- 信息清晰简介，信息展示提取信息更快更轻松
- 用户界面的设计，始终是点击优于输入
- 竖屏锁定
