## 一、工具概述

简易项目管理工具是 Project Pandora 项目的轻量级项目管理方案，以 Markdown 表格形式组织项目任务看板、里程碑、功能统计和风险跟踪，无需额外软件依赖，可直接在编辑器/飞书多维表格/Excel 中查看和维护。

**设计理念：**
- 轻量级：纯文本格式，无需安装项目管理软件
- 可导入：支持导入飞书多维表格或 Excel
- 易维护：随项目进展直接编辑 Markdown 表格
- 全景视图：Sprint 看板 + 里程碑 + 统计 + 风险一体化

## 二、功能说明

### 2.1 项目看板

按 Sprint 分组展示任务列表，每个任务包含以下字段：

| 字段 | 说明 |
|------|------|
| 任务ID | Sprint编号-序号，如 S1-01 |
| 任务名称 | 任务简要描述 |
| Epic | 所属 Epic 分组（Epic-1~6） |
| 状态 | ✅完成 / ⚠️待调整 / 🔄进行中 / 📋待开始 |
| 备注 | 补充说明或依赖关系 |

**当前看板包含5个Sprint：**
- Sprint 0：需求分析与产品设计（✅ 已完成）
- Sprint 1：首个MVP（✅ 已完成）
- Sprint 1.5：需求评审迭代（🔄 进行中）
- Sprint 2：试用版本交付（📋 待开始）
- Sprint 3：测试与验证（📋 待开始）

### 2.2 里程碑

以表格展示关键里程碑节点：

| 字段 | 说明 |
|------|------|
| 里程碑名称 | 阶段目标 |
| 目标时间 | 计划完成时间 |
| 状态 | ✅已达成 / 📋待开始 |
| 交付物 | 该里程碑的产出 |

### 2.3 功能完成度统计

按 Epic 分组统计已完成/待开发数量及完成率，一目了然掌握整体进度。

### 2.4 风险与待跟进

跟踪项目风险和待跟进事项：

| 字段 | 说明 |
|------|------|
| 风险项 | 风险描述 |
| 影响 | 对项目的影响 |
| 应对措施 | 解决方案 |
| 负责人 | 负责人员 |

### 2.5 实训交付要求进度

对照实训文档要求的8项交付清单，逐项标注完成状态。

## 三、使用方式

### 3.1 查看方式

1. **直接查看**：用任意文本编辑器/Markdown 预览器打开 `简易项目管理工具.md`
2. **Word 查看**：打开 `简易项目管理工具.docx`
3. **导入飞书**：将表格内容复制到飞书多维表格（单表上限2000行）
4. **导入 Excel**：将表格内容复制到 Excel 工作表

### 3.2 更新方式

随项目进展直接编辑 `简易项目管理工具.md`：
- 新增任务：在对应 Sprint 表格中添加行
- 更新状态：修改状态列（✅/⚠️/🔄/📋）
- 新增 Sprint：添加新表格段落
- 更新统计：修改功能完成度统计表

### 3.3 重新生成 docx

修改 .md 后运行转换脚本：
```
python docx/tasks/md_to_docx.py
```

## 五、与其他文档的关系

| 文档 | 关系 |
|------|------|
| 需求评审会议纪要 | 评审结论驱动看板任务调整 |
| 评审结论 | 不通过项（紧急程度）在看板中标注为⚠️待调整 |
| 问题清单 | 问题优先级对应看板任务优先级 |
| 产品需求迭代 | 迭代项在看板 Sprint 1.5/2 中跟踪 |
| 产品需求与设计文档 | Epic 定义来源 |
